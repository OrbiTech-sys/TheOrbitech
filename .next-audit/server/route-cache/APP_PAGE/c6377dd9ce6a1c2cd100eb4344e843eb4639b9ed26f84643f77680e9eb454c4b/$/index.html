How a project runs

Four steps, in this order, on every engagement.

  1. Scoping call

    Thirty minutes on the problem, the constraints and the timeline. No preparation needed.

  2. Written proposal

    Fixed-scope milestones with a price for each, and a plain list of what is out of scope.

  3. Two-week build cycles

    Every cycle ends with a working preview link and a short review with the people writing the code.

  4. Handover

    Code, infrastructure accounts and documentation are yours. Ongoing support is optional.
